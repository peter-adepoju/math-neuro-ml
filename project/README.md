# MAMBA project week: starter notebooks

One starter notebook for each of the eight project options in the Project Week Brief. Each one loads its data (a local copy in `../data/` first, otherwise a download from the repository pinned at commit `51d8822`), describes every array by shape and units, works one first step, and leaves headed `# TODO` cells for the minimum result. A check cell after each TODO prints *TODO* until the cell is done, then tests the result. Every starter runs top to bottom as delivered.
